# 기술 숙련도·근거 구성안

최초 작성일: 2026-10-14. 시안 구현: 2026-10-16.

## 새 기기에서 이어 진행한 시안

2026-10-16 사용자는 상세 내용과 실제 자기평가는 나중에 확정하고, 우선 맥락에 맞는 디자인을 확인하기로 했습니다. 로고·숙련도·한 줄 근거를 먼저 보여주고 클릭하면 상세를 펼치는 추천 구성을 확인했습니다. 현재 소개 영역에 이 시안을 구현했습니다.

- 백엔드와 데이터 / 연결과 실행 환경 / 화면 구현 세 분류에서 기술을 탐색합니다.
- 기술 행에는 원본 로고 또는 텍스트 약칭, 기술명, 한 줄 근거, 예시 등급, 펼침 아이콘을 표시합니다.
- 행을 클릭하거나 키보드로 열면 사용 경험과 기존 프로젝트 상세 링크가 나타납니다.
- `모두 펼치기`와 `모두 접기`로 긴 근거를 직접 노출한 구성을 비교합니다.
- 등급은 **상중 / 중 / 중하 / 하**의 디자인 확인용 값입니다. 화면에도 예시임을 표시했습니다. 실제 본인 평가로 확정하거나 공개 배포하지 않았습니다.
- 제공된 Java·Spring·MySQL·Redis·Docker·Git·React SVG 7개를 원본 그대로 `public/assets/skills/`에 모았습니다. 추가 로고를 만들지 않았습니다.

구현 위치: `src/SkillsSection.tsx`, `src/skillEvidence.ts`, `src/skills.css`. 실제 평가와 문구를 확정할 때는 `skillEvidence.ts`의 시안 데이터를 교체하고 예시 안내의 처리도 함께 결정합니다.

## 확정된 표시 방식

사용자 선택: 기술명·숙련도·대표 근거 한 줄을 먼저 보여주고, 클릭하면 상세 근거와 관련 프로젝트를 펼칩니다. 긴 근거를 처음부터 모두 노출하지 않습니다. 기존 회색·차콜 디자인을 유지합니다.

아래는 2026-10-14의 초기 계획입니다. 실제 숙련도는 본인 평가를 받아 표시합니다. 현재 시안의 예시 등급은 최종 평가와 구분합니다.

## 평가 기준 제안

| 등급 | 수행 범위 |
| --- | --- |
| 상 | 독립적인 설계·최적화와 복잡한 문제 해결, 선택 근거 설명 |
| 상중 | 주요 기능 독립 구현과 문제 진단·해결 |
| 중 | 문서를 참고해 필요한 기능 구현 |
| 중하 | 예제를 응용해 제한된 기능 구현 |
| 하 | 기초 개념 학습과 예제 실행 |

기준과 실제 등급은 본인이 확인할 항목입니다. 프로젝트 코드를 사용한 사실만으로 등급을 확정하지 않습니다.

위 근거는 기존 확인 기록과 로컬 소스에서 읽은 구현 범위입니다. 현재 등급이나 다른 기술의 전문성으로 환산하지 않습니다. 프로젝트 링크는 사이트의 관련 상세 모달로 연결하여 같은 내용을 다시 길게 복제하지 않습니다.

## 준비할 로고

대상: Java, Spring, MySQL, Redis, Docker, Git, React, TypeScript.

- SVG 또는 배경이 투명한 PNG 원본을 제공받습니다.
- Spring 로고는 Spring Boot·Spring Security에 함께 사용할 수 있습니다.
- 파일을 둘 폴더: public/assets/skills/.
- 실제 파일을 받으면 확장자·출처·비율을 확인하고 이름을 정리합니다.
- 초기 작성 시에는 로고가 없었습니다. 현재 제공된 7개 SVG는 `public/assets/skills/`에 있습니다. TypeScript 등 나머지 기술은 로고를 만들어 대체하지 않고 텍스트 약칭을 사용합니다.
