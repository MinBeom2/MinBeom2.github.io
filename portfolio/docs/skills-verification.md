# 기술 영역 시안 검증

검증일: 2026-10-16.

기존 밝은 회색·차콜 디자인의 소개 안에 기술 로고, 예시 등급, 한 줄 근거와 펼침 상세를 연결했습니다. 이번 등급은 디자인 확인용이며 실제 숙련도 평가를 확정하지 않았습니다.

## 빌드와 화면 동작

TypeScript 프로젝트 빌드와 Vite 프로덕션 빌드를 확인했습니다. 로컬 Chrome에서 1440×1100, 768×1024, 390×844, 320×740 네 화면 폭을 확인했습니다.

각 폭에서 기본 목록, 한 항목 펼침, 모두 펼침, 연결·실행 환경 분류, 화면 구현 분류, 숙련도 기준 총 6개 상태를 캡처했습니다. 24개 상태에서 페이지 가로 넘침, 기술 내용 잘림, 깨진 로고, 중복 ID, 브라우저 오류는 검출되지 않았습니다.

키보드 Enter로 상세 열기, 전체 펼침·접기, 분류 변경, 기술 근거에서 Ait 상세 모달 열기, Escape로 닫기와 진입 링크로 초점 복귀를 각 화면 폭에서 확인했습니다. 실제 iOS/Safari 검증이나 모든 보조 기술의 전체 접근성 검증은 아닙니다.

검사 스크립트와 캡처·원본 결과는 Git에서 제외한 `.impeccable/review/skills-capture.mjs`와 `.impeccable/review/skills/`에 보관합니다.

## 정적 디자인 검사

detector는 변경한 UI에 한 번 실행했습니다. 기존 디자인 문서의 대표 글자 크기와 다른 7개 font-size advisory가 기록됐습니다. 기술 제목 22px, 행 제목 15–17px, 보조 설명 11–13px은 이번 좁은 기술 목록의 크기 위계이며 차단 항목은 없었습니다. 원본 결과는 `.impeccable/review/skills/detector.json`에 보관합니다. 기존 문서 경로·토큰 체계를 이번 작업의 부수 변경으로 옮기거나 확장하지 않았습니다.

## 별도 디자인 검토

별도 finish reviewer가 원본 요청, 확정 답변, 기존 디자인 체계, 소스와 24개 화면을 읽고 검토했습니다. 유일한 필수 수정은 비선택 분류 버튼의 개수 글자 대비였습니다. 개수의 opacity를 제거해 기존 본문색을 그대로 사용하도록 수정했습니다.

같은 24개 화면을 다시 캡처하고 빌드·동작 검증을 통과했습니다. reviewer는 네 폭의 기본 화면에서 대비 수정이 해결됐고 이 수정으로 인한 회귀가 없다고 판단했습니다. 최종 판정은 **ship**, 판정 범위는 보고된 대비 수정의 해결입니다. 비선택 개수의 대비는 약 5.88:1입니다.

## 공개 상태

로컬 미리보기용 변경입니다. GitHub push와 공개 배포는 실행하지 않았습니다. 실제 등급과 세부 문구는 사용자가 디자인을 본 뒤 확정합니다.
