# 첫 화면 소개 영역 조정

2026-10-16 사용자가 소개를 더 크게 보여주고 첫 화면에서 프로젝트가 보이지 않도록 요청했다. 데스크톱과 모바일 모두 같은 방향을 적용하는 것을 확인했다.

소개에 헤더 높이를 뺀 최소 화면 높이를 적용했다. 제목은 두 줄을 유지하며 데스크톱에서 최대 80px로 확대했다. 이름과 본문도 함께 키우고, 소개 묶음을 화면 중앙보다 조금 위에 배치했다. 짧은 가로 화면에서는 내용에 따라 높이가 늘어나도록 해 글을 자르지 않는다.

Chrome에서 1440×1000, 1366×768, 1920×1080, 768×1024, 390×844, 320×740, 844×390, 361×740, 601×800의 아홉 화면을 확인했다. 모두 제목이 두 줄이며 가로 넘침이 없고 프로젝트가 첫 화면 아래에서 시작한다. 일반 세로 화면에서는 소개 본문이 첫 화면 안에 들어온다. 844×390의 짧은 화면에서는 소개가 자연스럽게 길어진다.

상단 프로젝트 메뉴 이동, Ait 상세 모달 열기와 Escape 닫기도 확인했다. TypeScript 검사와 Vite 빌드를 통과했으며 레이아웃 범위 detector 결과는 빈 목록이다. 캡처와 측정 기록은 Git에서 제외한 `.impeccable/review/hero-fullscreen/`에 있다.

새로운 배포 이미지 자산과 애니메이션은 추가하지 않았다.

별도 finish reviewer가 사용자 원본 이미지와 최종 캡처 10개, 소스와 갱신한 디자인 문서를 검토했다. 최종 판정은 `ship`이며 필수 수정 사항은 없다.
