# 구현·확인 기록

확인일: 2026-10-14.

## 적용한 요청

- 헤더의 이름·브랜드 마크·연락 버튼을 제거하고 프로젝트·작업 방식·소개를 중앙의 어두운 아일랜드에 배치했습니다.
- 현재 읽는 섹션에 따라 밝은 선택 표시와 aria-current가 이동합니다. 모달을 열면 프로젝트 메뉴가 선택됩니다.
- 프로젝트 상세는 홈 위의 native dialog로 표시합니다. 기존 내용·이미지·본문 디자인은 유지했습니다.

## 빌드

최종 `npm run build` 성공. TypeScript 검사와 Vite 배포 빌드를 완료했습니다. 이후 수정은 문서와 검증 기록뿐입니다.

## Playwright

사용자가 승인한 로컬 Chrome 별도 컨텍스트에서 다음 네 폭을 점검했습니다.

- 데스크톱 1440×1000
- 중간 폭 768×1024
- 모바일 390×844
- 좁은 모바일 320×740

각 폭의 홈·프로젝트·작업 방식·소개와 세 프로젝트 모달, 총 28개 화면 상태를 저장·검토했습니다.

- 세 메뉴 유지, 이름·마크·연락 버튼 제거, 실제 본문 너비 기준 중앙 정렬 확인.
- 메뉴 클릭 및 별도의 스크롤에 따른 선택 상태 확인.
- Ait·ONEWORK·SteamFolder 모달 열기, 배경 홈 유지·스크롤 고정 확인.
- Escape·닫기 버튼·모달 바깥 클릭, 닫은 후 위치와 진입 링크 포커스 복귀 확인.
- native dialog의 키보드 초점이 배경으로 빠지지 않는지 확인.
- 상세 목차가 닫기 도구줄 아래로 이동하는지 확인.
- 뒤로 가기로 닫기, 앞으로 가기로 다시 열기 확인.
- 기존 상세 해시 주소의 직접 접근·새로고침과 잘못된 프로젝트 복구 확인.
- 문서·모달 가로 넘침, 검사한 텍스트 대비 실패, 중복 ID, JavaScript console/page 오류 없음.

원본 캡처·JSON 결과·로컬 점검 스크립트는 Git에서 제외한 `.impeccable/review/island-modal/`에 보관합니다. 이 결과는 Chrome의 화면 폭별 점검이며 실제 iPhone/Safari 또는 모든 보조 기술의 전체 접근성 검증은 아닙니다.

## 디자인 검토

별도 finish reviewer가 28개 캡처와 소스를 검토했습니다. UI의 필수 수정은 없었으며, 디자인 문서의 모바일 글꼴 블록 중복·들여쓰기 지적을 복원하고 문서 재확인을 받았습니다. 최종 판정: **ship**.

정적 detector는 이번 변경에서 1회 실행했습니다. 대표 디자인 토큰 범위 밖의 일부 기존 반응형 글자 크기·중립색·모서리 값과 신규 모달 색에 대한 advisory가 표시됐습니다. 신규 값은 문서에 추가했고, 기존 변형은 읽기 위계를 보존하는 의도로 기록했습니다. detector 전체 출력은 도구에서 잘려 보존되지 않았으며 재실행하지 않았습니다. 이 기록은 detector가 clean이라는 주장을 포함하지 않습니다.

디자인 frontmatter의 mapping 문법·중복키·들여쓰기와 component radius 참조를 점검했습니다. 모바일 글꼴 정의는 typography 한 곳에 있으며 JSON sidecar도 정상 파싱됩니다. 이번 검토는 사용자가 지정한 아일랜드 헤더와 모달 변경 범위이며 별도 QUALITY BAR·승인 comp는 없습니다.

## 자료와 배포

사이트의 원본 이미지 4개는 이전에 기록한 출처 메타데이터를 유지했습니다. 아래 실제 최신 캡처 4개도 Playwright 출처를 임베딩했으며 누락은 없습니다.

GitHub push와 공개 배포는 실행하지 않았습니다. Pages workflow는 기존과 같이 portfolio 폴더에서 빌드하고 portfolio/dist를 배포합니다. 실제 Actions와 공개 사이트는 push 후 확인해야 합니다.
