# 홈 간소화와 프로젝트 타일 검증

검증일: 2026-10-16.

사용자가 첨부 이미지에서 표시한 홈의 Ait 검증 카드, 프로젝트 살펴보기·GitHub 버튼, 주 사용 기술 목록, 소개의 GitHub 링크를 제거했습니다. 프로젝트 목록의 서로 다른 대형 구성을 같은 크기의 정사각 타일 세 개로 바꿨습니다. 타일에는 로고 또는 기존 폴더 아이콘과 프로젝트 이름만 표시합니다.

프로젝트 기록과 실제 화면, 검증 근거는 기존 상세 모달에서 읽습니다. 클릭하면 220ms 확대 효과로 열리고, reduced motion 설정에서는 애니메이션을 끕니다. SteamFolder 아이콘은 공식 로고가 아닌 기존 아이콘 체계의 중립 폴더 형태입니다.

## 확인 결과

- TypeScript 프로젝트 검사와 Vite 프로덕션 빌드 통과.
- Chrome의 1440×1000, 768×1024, 390×844, 320×740에서 각 7개 상태, 총 28개 화면을 확인.
- 삭제한 요소의 DOM 부재, 모든 타일의 동일 크기·정사각 비율 확인.
- 홈·프로젝트·작업 방식·소개와 세 프로젝트 상세에서 문서·모달 가로 넘침, 텍스트 대비 실패, 중복 ID, 브라우저 오류 없음.
- 세 모달 열기, Escape·닫기·배경 클릭, 스크롤·초점 복귀, 모달 내 목차, 배경 초점 차단, 뒤로·앞으로, 직접 해시·새로고침 확인.

실제 iOS/Safari나 모든 보조 기술의 전체 접근성 검증은 아닙니다. QA 스크립트·캡처·JSON 결과는 Git에서 제외한 `.impeccable/review/project-tiles/`에 있습니다.

정적 detector는 이번 변경에 한 번 실행했습니다. 기존 stylesheet 전체를 대상으로 글자 크기 53개, 색 5개, 모서리 2개의 토큰 advisory가 기록됐습니다. 이는 기준 문서의 대표 토큰과 기존 세부 값의 차이를 포함하며 clean 판정으로 표현하지 않습니다. 원본은 같은 QA 폴더의 `detector.json`입니다.

별도 finish reviewer가 사용자 표시 이미지 두 장, 28개 화면, 소스와 갱신한 디자인 문서를 검토했습니다. 최종 판정은 **ship**, 필수 수정 항목은 없습니다. 키보드 Enter로 열기와 220ms 확대, reduced motion의 animation none, Escape 후 타일 초점 복귀도 별도로 확인했습니다.

GitHub push와 공개 배포는 실행하지 않았으며 로컬 미리보기에서 확인합니다.
