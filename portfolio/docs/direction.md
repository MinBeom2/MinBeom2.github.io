# 디자인 구현 기준

## 사용자가 확정한 방향

- 밝은 회색 바탕과 차콜 글자의 모던한 색감.
- 프로젝트마다 상세 모달. 기존 독립 페이지 선택은 2026-10-14 사용자 요청으로 변경.
- 코드로 구현하고 실제 브라우저에서 검토.
- 제공한 증명사진, Ait 앱 아이콘, ONEWORK 실제 화면 사용.
- ONEWORK 로고는 원래 프로젝트 폴더에서 찾아 가져오기.
- Ait 화면은 사용자가 나중에 직접 캡처. 미확인 콘텐츠·자산은 임의로 만들지 않기.

## 범위와 구성

현재 홈의 소개 → 프로젝트 → 작업 방식 → 기술·학력 → 연락 흐름을 유지하며 회색 디자인 체계를 전체에 적용한다. 큰 구조와 기존 글꼴의 역할을 유지하는 refinement이며, 사용자가 요청한 프로젝트 모달과 중앙 아일랜드 내비게이션을 적용한다. 새로운 은유·시각 세계나 모방 사이트를 임의로 선택하지 않는다.

홈은 Experience, 프로젝트 상세는 Read 모드다. 첫 화면은 한 열 소개이며, 다음 프로젝트 영역에서는 같은 크기의 작은 정사각 타일에 로고와 이름만 표시한다. 본인 사진은 소개 영역에 배치한다. 긴 문제 해결 기록과 검증 조건은 해당 상세에서 읽는다.

## 시스템

- 바탕: 밝은 회색 #f4f4f4
- 본문: 차콜 #262626
- 표면: 흰색 #ffffff
- 보조 글자: 중립 회색, 일반 텍스트 대비 4.5:1 이상
- 경계: 밝은 중립 회색
- 선택과 강조: 차콜과 회색 농도로 구분
- 원본 로고와 실제 화면의 색은 유지
- 한국어 Noto Sans KR Variable, 영문 프로젝트명·수치 Manrope Variable
- 본문 15–16px 중심, 보조 설명 12px 이상, 버튼 영역 44px 이상
- 왼쪽 정렬, 읽기 폭 제한, 같은 역할의 제목·간격을 일관되게 정리

## 첫 화면과 상호작용

제목·이름·소개를 한 열로 보여주고 프로젝트까지의 여백을 줄인다. 사용자가 삭제를 지정한 홈 Ait 검증 패널, 프로젝트·GitHub 버튼, 주 사용 기술 목록과 소개 GitHub 링크는 제거했다. 데스크톱 프로젝트 제목 옆에 최대 184px 정사각 타일 세 개를 두고, 1100px 이하에서는 164px, 960px 이하에서는 제목 아래 목록으로 접는다. 모바일은 최대 160px 두 열이다. 타일 선택으로 기존 상세 모달을 열며 220ms 확대 반응은 reduced motion에서 끈다.

상세 모달은 실제 프로젝트 정체성, 기간·팀·역할을 먼저 읽은 후 문제·담당·기술·검증·결과·근거를 탐색한다. 데스크톱 목차는 읽는 동안 접근할 수 있고 모바일에서는 본문 앞 목차로 제공한다. 기존 해시 경로로 공유·새로고침해도 홈 위에 모달로 열린다. Escape·닫기·배경 클릭과 뒤로 가기로 닫으며 스크롤·초점이 복귀한다.

## 품질 기준

전체 홈 폭은 1120px, 일반 영역의 세로 여백은 72px·태블릿 56px·모바일 44px로 모은다. 소개의 사진과 글은 데스크톱 왼쪽에 묶고 820px 이하에서는 기술 위에 가로로 배치한다. 기술의 예시 안내와 모두 펼치기를 같은 줄에 정리하고, 근거 한 줄과 펼친 경험의 크기를 구분한다. 모바일 상세는 기간·구성 두 열과 전체 폭 역할, 두 열 목차로 첫 본문까지의 거리를 줄인다. 실제 색·글꼴·자산·사실과 기존 상호작용은 유지한다.

데스크톱, 모바일, 사용자의 브라우저 실제 폭을 한 배치로 검토하고 드러난 문제를 묶어 수정한다. 필요하면 한 번의 확인 배치 후 별도 reviewer에게 넘긴다. 텍스트 대비, 작은 화면의 넘침, 이미지 비율·설명, 목차 이동, 뒤로 가기, 직접 접근·새로고침, 포커스, reduced motion을 검증한다.

## 2026-10-14 헤더 변경

중앙의 어두운 캡슐에 프로젝트·작업 방식·소개를 표시한다. 이름·브랜드 마크·연락 버튼·모바일 메뉴 토글은 헤더에서 제거한다. 현재 읽는 섹션은 밝은 선택 표시와 aria-current로 나타낸다. 전환은 사용자 탐색에 반응하며 reduced motion에서는 즉시 변경한다.
