## 정보 구성

목차와 본문의 담당 구현을 나의 역할로 통일했다. 짧은 역할 요약, 핵심 기여, 결과, 역할 분담 순서로 읽는다. 결과는 기존 마지막 영역에서 이곳으로 이동해 중복하지 않는다. SteamFolder는 개인 프로젝트이므로 기획과 설계, 백엔드, 프론트엔드의 직접 담당 범위를 표시한다. 기존 scope, results, collaboration 주소는 유지하며 각 묶음으로 직접 이동한다.

Ait의 브랜치 가이드 항목과 링크를 제거했다. 홈과 Git 기술의 collaboration 주소는 역할 분담으로 연결되며 홈 링크 이름도 팀 내 역할 보기로 바꿨다.

## 저장소

프로젝트 소개 아래의 저장소와 Notion 프로젝트 링크를 제거하고 모달 도구줄 왼쪽에 GitHub 링크를 표시했다.

- Ait: https://github.com/MinBeom2/Ait
- ONEWORK: https://github.com/MinBeom2/OneWork
- SteamFolder 백엔드: https://github.com/MinBeom2/SteamFolder
- SteamFolder 프론트엔드: https://github.com/MinBeom2/SteamFolder-front

Ait와 ONEWORK는 사용자가 이번 대화에서 제공한 주소다. SteamFolder는 기존 두 저장소를 사용한다. 단일 저장소는 GitHub 아이콘 하나, 두 저장소는 각각 백엔드와 프론트엔드 이름을 함께 표시한다. 링크의 접근 가능한 이름에는 프로젝트, 저장소 범위와 새 탭 동작을 담았다. 문제 해결의 개별 커밋과 성능 검증 원본 링크는 보존했다.

## 내용 근거와 한계

- Ait의 백엔드 3명, 프론트엔드 2명, AI 1명 구성은 C:/S15P11D202/README.md의 팀 소개에 근거한다. 개인 구현은 기존 커밋 검토와 사용자 확인 범위다.
- Ait 채팅의 5만 건, 최신 50건, Vuser 50, 1분과 평균 응답 시간 1,804.71ms 및 131.59ms는 개발 및 검증 기록이다. 운영 트래픽 성과로 바꾸지 않았다.
- 좋아요 정합성 검증은 팀 종료 후 개인 브랜치이며 팀 배포본에 반영되지 않았음을 결과에도 표시했다.
- ONEWORK는 커밋 검토에서 확인한 영상 관제 담당을 설명한다. 분야별 인원은 미확인으로 사용자에게 질문했다. 인원은 추정하지 않고 본인 영상 관제와 다른 팀원의 데이터 처리, 분석 및 화면 범위만 구분했다.
- ONEWORK의 HTTPS 혼합 콘텐츠 차단은 미해결이다. 지연시간이나 운영 성과를 새로 주장하지 않았다.
- SteamFolder는 로컬 개발 중이며 외부 배포와 사용자 피드백은 계획이다.
