# 프로젝트 상세의 링크와 검증 설명 정리

2026-10-22 사용자 요청에 따라 세 프로젝트 상세를 함께 정리했다.

## 제거한 항목

- 검증별 커밋과 Notion 링크 열 개 목록 및 성능 측정과 AI 연동 아래의 관련 자료 링크를 제거했다.
- 공통 CaseSources 컴포넌트, CaseStudy의 sources 필드와 커밋 URL 생성 함수, 사용하지 않는 Notion 주소와 스타일을 제거했다.
- 상세 끝의 ‘다른 프로젝트도 살펴보기’를 세 프로젝트에서 공통으로 제거했다.
- Ait의 깊은 커서 미검증 문장과 좋아요 검증의 개인 브랜치 및 처리량 미측정 주석을 제거했다. ‘최신 50건’은 채팅 측정의 조건 칸으로 옮겼다. 프로젝트 종료 후 좋아요 추가 검증과 팀 배포 미반영은 기존 제목과 결과에 남아 있다.

상단 GitHub 저장소 아이콘과 닫기, 현재 목차 및 직접 주소, 기술 비교의 공식 문서 참조는 보존했다.

## 게시글 목록 성과 제외

`_workspace/ngrinder-review-2026-10-20/findings.md`를 다시 확인했다. 36번 테스트는 Response_errors가 전체 69,386건이고 보관된 일부 로그에는 HTTP 401과 AUTH_005가 있다. 기록된 요청은 검색 매개변수 없는 `/api/posts?page=0~4&size=10&sortType=LATEST`다. 이 기록을 검색 실험으로만 설명했던 기존 분류는 부정확하다. 각 오류 응답의 코드까지 전수 확인한 것으로 확대하지 않는다.

사용자 요청에 따라 게시글 목록의 26,010.99ms와 463.55ms, TPS 3.11과 114.25 행을 포트폴리오에서 제거했다. 해당 숫자 각각을 이 오류 테스트와 직접 대응해 확정한 것은 아니다. 정상 조회 성과로 보여주지 않도록 목록의 성능 비교 자체를 제외했으며 관련 Count 및 배치 조회 개선 설명도 검증 사례에서 덜어냈다. 성능 표에는 알림, 채팅과 댓글 세 항목만 남긴다. 게시글과 댓글 등 실제 구현 기능까지 삭제하거나 실패한 기능으로 바꾸지는 않는다.

## 문구 검토

확인한 범위로 작성한 수정 초안은 humanize-korean light 경로로 검토했다. run_id는 `2026-10-22-007-2727`이며 기존 소스와 초안을 함께 보존했다. 독립 monolith 역할은 추가로 수정할 패턴이 없어 초안을 유지했다. 공통 게이트 exit 0, 변경률 0%, 등급 B, 자체검증 6/6, 잔존 finding 및 경고 없음이다. light 경로이므로 별도 진단과 finalizer는 실행하지 않았다. 변경률은 사실 초안과 윤문본 사이의 차이다.

## 확인 범위

이 세션에서는 브라우저 보안 정책의 제한을 우회하지 않고 첨부 화면과 현재 소스를 기준으로 수정했다. 실제 브라우저 및 모바일 렌더는 이번 변경에서 확인하지 못했다. 빌드와 정적 검사 결과는 아래에 기록한다.

- TypeScript 검사와 Vite 프로덕션 빌드, `git diff --check`를 통과했다.
- 제거한 자료 컴포넌트, sources 필드, 커밋과 Notion 주소, 하단 탐색 및 두 긴 주석의 참조가 소스에 남지 않았음을 확인했다. 성능 표는 세 행이며 최신 50건 조건과 프로젝트 저장소 네 주소는 보존됐다.
- Impeccable 정적 탐지기를 한 번 실행해 JSON 결과를 run 폴더에 보관했다. 기존 글자 크기 56건과 모서리 1건의 advisory, SFMono-Regular 코드 글꼴의 문서 미등록 warning 1건이 있다. 작업 시작 시의 소스와 각 탐지 줄을 대조했으며 58건 모두 기존 코드다. 새 디자인 규격이나 경고 숨김 예외를 추가하지 않았다.
- Ait 서버나 nGrinder 실험을 이번에 다시 실행한 것은 아니다. 기록의 포함 범위와 포트폴리오 표시를 바로잡는 작업이다.

## 후속 요청: 기간과 ONEWORK 안내

ONEWORK 기술 선택의 ‘한계와 확인 범위’ 제목과 해당 지연시간 및 HTTPS 안내 문단을 제거했다. 항목이 없으면 빈 제목이나 문단을 출력하지 않도록 limitation을 선택 항목으로 바꿨다. 다른 프로젝트의 해당 안내는 유지한다.

세 상세의 기간 라벨은 ‘기간’으로 통일했다. SteamFolder 백엔드와 프론트엔드의 전체 로컬 Git 이력이 shallow 상태가 아님을 확인하고 첫 커밋을 읽었다. 백엔드 `54a3759cf772163ab3e87eb83b501cc30fb10164`는 2026-08-21 10:33:36 +09:00, 프론트엔드 `7d3f4d0c132a692e8659febd6da4122ce3f1d8be`는 2026-08-25 15:37:39 +09:00이다. 더 이른 백엔드 날짜를 사용해 ‘2026.08.21 ~ 진행 중’으로 표시했다. 프로젝트 저장소는 읽기 전용으로 확인했다.
