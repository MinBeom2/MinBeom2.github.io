# 중복 개념도 정리

2026-10-22 사용자가 첨부한 Ait 기능 요약과 유사한 표현을 검토했다. 채용 담당자가 프로젝트 소개, 역할과 기술 판단을 읽는 Read 표면의 제한된 정리다.

## 제거 및 통합

| 기존 표현 | 처리 | 내용이 남아 있는 곳 |
| --- | --- | --- |
| Ait 기능 요약 박스 | 삭제 | 나의 역할의 스터디 운영과 채팅, 커뮤니티와 알림 설명 및 사용 기술과 적용 내용 |
| ONEWORK 영상 전달 순서 박스 | 삭제하고 중복 문장 통합 | 기술 선택 본문의 FFmpeg 인코딩, MediaMTX 중계와 Unity WebGL 및 HTML 영상 창 설명 |
| SteamFolder 폴더 예시 | 삭제 | 프로젝트 소개의 폴더로 게임 정리 및 쇼케이스 링크 공유, 나의 역할의 게임 분류와 화면 구현 |

삭제한 세 컴포넌트와 전용 CSS, 사용하지 않는 import 및 영상 전달 경로 필드를 정리했다. 실제 비교에 필요한 성능 표와 기술 비교, AI 피드백의 저장 및 분류 순서와 알림 조건은 유지했다. 목차, 직접 주소, 닫기, 실제 프로젝트 화면과 근거 링크는 보존했다.

## 문구 확인

ONEWORK의 기존 구현 설명과 전달 경로에서 사실을 모아 두 문장으로 정리했다. humanize-korean run_id는 `2026-10-22-006-ca3a`다. light 경로의 독립 monolith 역할이 연결어미 뒤 쉼표 한 곳을 제거했다. 공통 게이트 exit 0, 변경률 0.3%, 등급 B, 자체검증 6/6이며 남은 finding과 경고는 없다. light 경로이므로 별도 진단과 finalizer는 실행하지 않았다. 이 변경률은 사실 초안과 윤문본 사이의 차이다. 원래 코드와 초안은 run 폴더에 보존했다.

## 확인 범위

브라우저의 기존 로컬 오류 탭을 선택하는 동작이 보안 정책으로 거절됐다. 대체 브라우저나 다른 조작 방식으로 우회하지 않았다. 첨부 화면과 현재 소스의 구조를 기준으로 수정했으며 수정 후 실제 브라우저 렌더와 모바일 화면은 이번 작업에서 확인하지 못했다. 빌드 및 정적 검사 결과는 아래에 기록한다.

- TypeScript 검사와 Vite 프로덕션 빌드, `git diff --check`를 통과했다.
- 소스에서 제거한 세 컴포넌트와 영상 전달 경로 필드의 참조가 남지 않았음을 확인했다. 전용 CSS 규칙은 styles.css에서 49개, case-studies.css에서 3개를 제거했다.
- Impeccable의 정적 탐지기를 한 번 실행했다. 기존 본문의 글자 크기와 모서리 값이 디자인 문서의 단계와 다르다는 advisory가 나와 종료 코드는 1이었다. 기존 규격의 차이를 이 작업에서 임의로 수정하거나 경고를 숨기는 예외를 추가하지 않았다.
- 작업 시작 시 보관한 소스와 최종 소스의 차이를 대조했다. 새 레이아웃이나 장식은 추가하지 않았고 영상 전달 설명과 도식 제거에 필요한 변경만 적용했다.
