# 전체 흐름 디자인 다듬기

검증일: 2026-10-16.

사용자가 소개와 프로젝트를 더 가깝게 배치하고 홈·기술·상세 화면을 함께 정돈하는 방향을 확인한 뒤 진행했습니다. 기존 회색·차콜, 원본 로고, 삭제한 홈 요소와 로고·이름만 있는 정사각 타일은 보존했습니다.

## 변경

- 최대 읽기 폭을 1120px로 모으고 소개·섹션 간격을 줄였습니다. 데스크톱에서는 프로젝트 제목과 세 타일을 나란히 배치합니다.
- 320px의 홈 제목을 두 줄로 정리하고 타일 로고의 시각적 크기를 조정했습니다.
- 820px 이하의 소개는 한 열로 전환하고 사진과 소개 문구를 나란히 묶었습니다. 데스크톱에서는 소개를 읽는 동안 프로필 열을 유지합니다.
- 기술 영역은 예시 등급 안내와 전체 펼침을 한 줄로 묶고 설명의 가독성을 높였습니다.
- 상세의 기간·구성·역할을 데스크톱 세 열, 모바일 두 열과 전체 폭 역할로 배치했습니다. 모바일 목차는 44px 클릭 높이를 유지하며 두 열로 표시합니다.
- 이전에 삭제한 홈 검증 패널과 버튼 관련 미사용 CSS를 정리했습니다.

## 확인

TypeScript 프로젝트 검사와 Vite 프로덕션 빌드를 통과했습니다. 로컬 Chrome에서 다음 화면을 확인했습니다.

- 홈·프로젝트·작업 방식·소개·세 프로젝트 모달: 1440×1000, 768×1024, 390×844, 320×740의 28개 상태.
- 기술 기본·개별 펼침·모두 펼침·연결 환경·화면 구현·숙련도 기준: 같은 네 폭의 24개 상태. 기술 캡처의 데스크톱 높이는 1100px입니다.

52개 상태에서 페이지·모달 가로 넘침, 내용 잘림, 깨진 기술 로고, 중복 ID와 브라우저 오류가 검출되지 않았습니다. 홈·모달 28개 상태는 기존 텍스트 대비 검사도 통과했습니다. 네 폭의 제목 두 줄, 동일 크기 정사각 타일, 데스크톱에서 700px 이전에 나타나는 프로젝트도 확인했습니다.

개별·전체 펼침과 분류 전환, 키보드 Enter, 프로젝트 연결, 닫기·Escape·배경 클릭, 뒤로·앞으로, 직접 해시·새로고침, 진입 링크 초점·스크롤 복귀를 확인했습니다. 실제 iOS/Safari나 모든 보조 기술의 전체 접근성 검증은 아닙니다.

스크립트·화면·결과는 Git에서 제외한 `.impeccable/review/polish/`에 있습니다. detector는 변경한 UI 전체에 한 번 실행했으며 글자 크기 53개·색 4개·모서리 2개의 토큰 advisory를 기록했습니다. 기존 세부 값과 대표 토큰의 차이를 포함하며 clean 판정으로 표현하지 않습니다.

별도 finish reviewer가 52개 캡처, 원본 요청과 확인 답변, 소스와 갱신한 디자인 문서를 검토했습니다. 최종 판정은 **ship**, 이번 범위의 필수 수정은 없습니다. 문서 담당자는 기존 디자인 체계를 보존하면서 실제 레이아웃·타이포·동작에 맞춰 기록했습니다.

로컬 미리보기용 변경이며 GitHub push와 공개 배포는 실행하지 않았습니다.
